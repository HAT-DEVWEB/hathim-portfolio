## 🛠️ Technical Stack

- **Frontend Core**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, custom design tokens, fluid responsive `clamp()` typography
- **3D Graphics**: Three.js, WebGL with graceful fallback handling
- **Sound Design**: Procedural Web Audio API synthesizer (pen-paper friction, tactile mechanical switch clicks, spatial 3D inspection sounds) — 0 external audio dependencies
- **Icons**: Lucide React

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/HAT-DEVWEB/hathim-portfolio.git

# Navigate into the project
cd hathim-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.

### Production Build

```bash
npm run build
```
